# Amber Bead on a Quiet Pond

A tiny program that writes one short, relaxing text for the AI judge — a single amber bead on a quiet pond at dawn, ripples widening until the water remembers its depth.

## Run

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (199 characters, UTF-8, no trailing newline).
